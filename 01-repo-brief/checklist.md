# Brief Checklist

## Before committing

- [ ] Explain what the repo does and for whom in two sentences or fewer.
- [ ] State the stack and supported versions.
- [ ] Run every documented command from its stated directory before committing.
- [ ] Record successful results; resolve all command placeholders.
- [ ] Keep the brief to one page; move path-specific detail to scoped rules.
- [ ] Remove secrets, customer data, internal URLs and one-off task requests.
- [ ] Remove tone, persona and "see the wiki" instructions.
- [ ] Check that nothing contradicts a path rule or package AGENTS.md.
- [ ] Ask a repo question in VS Code chat and check the References list for the brief.
- [ ] Confirm the answer follows the relevant rules; References proves inclusion only.
