# Working on This Kit

Everything under `01-repo-brief` through `06-champion-playbook` is template or
teaching content, not instructions for working on this repository.

## Commands

Use Node.js 22 or newer. Set up with `npm ci --ignore-scripts`.
Run `npm run validate` before committing. This kit has no application build.

## Boundaries

- Preserve inert template filenames; never activate examples in this kit.
- Use Australian English and `{{PLACEHOLDER}}` values in templates.
- Verify Copilot claims against the supplied sources; mark gaps with `<!-- TODO: verify -->`.
- Keep examples synthetic; never add secrets, customer data or internal URLs.
- Keep one H1 per Markdown file and resolve every relative link.
- Commit only when requested; never push without permission.
